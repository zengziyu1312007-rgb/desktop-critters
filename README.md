# 桌面有点脏 · Desktop Critters

蟑螂和蚂蚁住进你的 Mac 桌面。投食、繁殖、围攻、巨化，再用拖鞋和扫把收拾战场。

当前版本：**v0.7.2**，macOS 原生 Swift / AppKit 应用。

## 下载与开启

在本仓库的 **Releases** 页面下载 `DesktopCritters-v0.7.2-macOS-arm64.zip`，解压后双击 **桌面有点脏.app**。

- 支持 Apple Silicon Mac（M1 及后续芯片），macOS 13 或更新系统。
- 运行时不需要 Python、Node.js 或其他第三方依赖。
- 当前应用使用本机临时签名，尚未进行 Apple Developer ID 签名与公证。

启动后默认为全桌面陪伴，虫群自行觅食和成长，鼠标可以穿透。

## 面板在哪里

- 顶部菜单栏点 **桌宠 → 打开控制面板**。
- 点击 Dock 中的应用图标，可以再次显示面板。
- 应用在前台时按 **⌘0**。
- 面板右上角 **−** 用来收起面板；**退出** 用来关闭应用。

## 怎么玩

| 操作 | 效果 |
| --- | --- |
| 投食 | 选择饼干、蛋糕、奶酪、草莓、巨型披萨或整块蛋糕，再点桌面；食物逐口出现缺损 |
| 喂给虫子 | 选择食物后点虫体；实际吃到的一口会推动成长，进食有冷却 |
| 搬个家 | 按住虫子拖动到其他地方 |
| 拍死 | 用拖鞋拍击；死亡后留下尸体 |
| 扫把 | 点按或拖动，扫走尸体、卵和外敌残骸 |
| 放卵 | 手动放下蟑螂卵鞘或蚁卵，等待孵化 |
| 今日战报 | 查看运行期间的出生、伤亡、成长和外交事件，也可手动停火或建交 |
| 引来蜘蛛／甲虫 | 触发蜘蛛缠丝或甲虫冲撞抢粮，每次最多一只活外敌 |

有五个成长阶段，中小型虫占多数；每阵营同时最多一只顶级巨虫。最大巨蟑包含腿和触角的标定外接范围约占四分之一活动区，最大巨蚁虫体长约为巨蟑的一半。普通零食维持普通体型，后续巨化需要大餐和空余名额。

虫群可以进行单挑、围攻和冲撞；交战死亡会真正减少人口。停火只阻止两阵营互打，成虫仍会反击外敌。成长和繁殖采用游戏规则。

**开一局** 会重建当前虫群，开始一场 150 秒计分对局；日常陪伴可以一直保留现有生态。

| 1 / 2 / 3 / 4 | 投食 / 搬个家 / 拍死 / 扫把 |

## 从源码构建

安装 Xcode Command Line Tools，然后在仓库根目录运行：

```sh
bash build.sh
```

输出：`dist/桌面有点脏.app`。脚本使用本机 macOS SDK、Swift 编译器与临时代码签名，不下载第三方依赖。重新构建前请退出本目录构建出来的运行实例。

运行行为检查：

```sh
./dist/桌面有点脏.app/Contents/MacOS/DesktopCritters --self-test
```

当前包含 100 项行为检查，覆盖取食、生命周期、人口名额、体型比例、拍击、扫把、外交、外敌与存档恢复。长时间 GUI 性能、Intel Mac 和 Windows 版本尚未验证。

## 本机存档

应用约每 15 秒及退出时自动保存：

```text
~/Library/Application Support/DesktopCritters/ecology-v1.json
```

关闭期间不进行离线繁殖。仓库与安装包不包含个人虫群存档或战报。

## 工程结构

```text
Sources/
  World.swift       # 生态、成长、战斗、存档与行为检查
  Drawing.swift     # 虫体、食物、道具与特效绘制
  Interface.swift   # 控制面板
  main.swift        # AppKit 应用、窗口、菜单与生命周期
Resources/
  Textures/         # 必需的虫体素材
  AppIcon.icns
  素材署名.txt
build.sh
```
