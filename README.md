# 桌面有点脏 · Desktop Critters

选两种宠物，让它们住进电脑桌面。奶龙对老鼠、蟑螂对蚂蚁，或两张自己上传的图片：投食、繁殖、围攻、巨化，再用杀虫剂、拖鞋和扫把收拾战场。

同一个仓库维护两套原生桌宠：**Mac v0.11.1**（Swift / AppKit）和 **Windows v0.11.0**（C# / WPF）。

Mac v0.11.1把喷药道具换成醒目的红黄大喷罐，瓶身竖排“敌敌畏”；喷射时有喷头按压、后坐力、亮色射流和液滴。

项目默认只更新Mac；Windows在明确提出更新时另行处理，当前保留v0.11.0。

v0.11.1将角色换装与生态统一：左右两队都能独立选角色或导入图片，保留飞行、五类外敌、可见产卵、文件夹藏卵与杀虫剂。旧版包继续保留。Mac的Bundle ID和原存档路径保留。Windows独立安装与保存，不读取或覆盖Mac存档。完整[跨平台安排](docs/cross-platform.md)和[Windows说明](windows/README.md)。

当前两个平台都尚未进行商业证书签名／公证，系统可能显示发布者提示。首版Windows的多屏、部分缩放与实际鼠标体验仍待更多真机反馈。

启动后默认为全桌面陪伴，虫群自行觅食和成长，鼠标可以穿透。

## 面板在哪里

Windows：双击系统托盘图标，或从任务栏打开控制台；Ctrl+0在应用前台时找回。以下是Mac入口：

- 顶部菜单栏点 **桌宠 → 打开控制面板**。
- 点击 Dock 中的应用图标，可以再次显示面板。
- 应用在前台时按 **⌘0**。
- 面板右上角 **−** 用来收起面板；**退出** 用来关闭应用。

## 选择两队宠物

点控制面板上的 **左队** 或 **右队**，打开同一个角色库。Mac顶部“桌宠”菜单也有“选择两队宠物与自定义图片”，应用内可按 ⌘K；Windows从控制面板或托盘进入。

- 两队各自选择：蟑螂、蚂蚁、老鼠，以及奶龙、奥特曼、牛来、乌萨奇、卡皮巴拉、LABUBU、Bongo猫、黄袋鼠，共11个内置选项。
- 先选左队／右队，再点角色；同款也能分属两队。双方可以各自导入不同图片，已导入图片可供任一队选择。
- 支持20MB以内的PNG、JPEG、GIF首帧；透明PNG效果更好。最多保存32个自定义角色，图片与原件只留在本机。
- “蟑螂 × 蚂蚁”恢复原始组合，不重开生态、不删除自定义图库。旧换装版的形象迁移至右队，左队保持蟑螂。
- 任一队选择蟑螂，都能展翅飞行；其他形象不长蟑螂翅膀。两队均参与吃食、成长、战斗、游戏产卵和孵化，喷药均可造成死亡，尸体可清扫。外敌老鼠与玩家选择的老鼠分别行动。

内置卡通角色沿用四姿态与程序动画；自定义单图随动作弹跳、缩放、出招和倒下，不会自动生成完整骨骼或额外姿态。左右队沿用各自的繁殖、人口和战斗规则，选择形象不会重置生态数值。角色设置独立保存在 `appearance-v1.json`，生态存档路径不变。

## 怎么玩

| 操作 | 效果 |
| --- | --- |
| 投食 | 选择饼干、蛋糕、奶酪、草莓、巨型披萨或整块蛋糕，再点桌面；食物逐口出现缺损 |
| 喂给虫子 | 选择食物后点虫体；实际吃到的一口会推动成长，进食有冷却 |
| 搬个家 | 按住虫子拖动到其他地方 |
| 拍死 | 用拖鞋拍击；蟑螂挤压后爆出黄褐色汁液，留下污渍和尸体 |
| 杀虫剂 · 0 | 点击或拖动喷雾，覆盖到的两队宠物死亡，留下尸体与污渍；卵保留，扫把负责清理 |
| 惊飞蟑螂 · 8 | 成蟑展开翅膀绕飞后落地；自然也会偶尔起飞，附近拖鞋会惊飞幸存者 |
| 藏卵处 · 9 | 选择工具后点击桌面文件夹图标；附近成虫会在该位置产卵，卵躲到图标后，孵化幼体从边缘出来；再点同处取消 |
| 扫把 | 点按或拖动，扫走尸体、汁液污渍、卵和外敌残骸 |
| 放卵 | 手动放下左队或右队的卵，等待孵化 |
| 今日战报 | 查看运行期间的出生、伤亡、成长和外交事件，也可手动停火或建交 |
| 引来外敌 | 触发蜘蛛缠丝、甲虫冲撞、蜈蚣连续追咬、蛇蓄势单点扑咬或老鼠抢粮冲散，每次最多一只活外敌 |

产卵时成虫停住，腹部轻抬，卵从尾部排出，完成后才开始孵化。藏卵处由用户手动指向文件夹图标，程序不读取或改动文件；观察工具可临时查看藏住的卵。移动桌面文件夹图标后，需在新位置重新标记。

有五个成长阶段，中小型虫占多数；每阵营同时最多一只顶级巨虫。最大巨蟑包含腿和触角的标定外接范围约占四分之一活动区，最大巨蚁虫体长约为巨蟑的一半。普通零食维持普通体型，后续巨化需要大餐和空余名额。

虫群可以进行单挑、围攻和冲撞；交战死亡会真正减少人口。停火只阻止两阵营互打，成虫仍会反击外敌。成长和繁殖采用游戏规则。

**开一局** 会重建当前虫群，开始一场 150 秒计分对局；日常陪伴可以一直保留现有生态。

## 从源码构建

Windows构建见 [windows/README.md](windows/README.md)，核心有独立行为检查；下方是Mac构建：

安装 Xcode Command Line Tools，然后在仓库根目录运行：

```sh
bash build.sh
windows/             # Windows原生工程、安装器与检查
tests/               # Windows核心和下载入口检查
docs/                # 统一下载页
```

输出：`dist/桌面有点脏.app`。脚本使用本机 macOS SDK、Swift 编译器与临时代码签名，不下载第三方依赖。重新构建前请退出本目录构建出来的运行实例。

运行行为检查：

```sh
./dist/桌面有点脏.app/Contents/MacOS/DesktopCritters --self-test
```

当前包含核心行为与新增功能检查，覆盖取食、生命周期、人口名额、体型比例、拍击爆浆、汁液持久化与清扫、外交、外敌与存档恢复。长时间GUI性能和Intel Mac尚未验证；Windows另有核心与原生窗口检查，见其构建说明。

## 本机存档

应用约每 15 秒及退出时自动保存：

```text
~/Library/Application Support/DesktopCritters/ecology-v1.json
```

关闭期间不进行离线繁殖。仓库与安装包不包含个人虫群存档或战报。

```text
windows/             # Windows原生工程、安装器与检查

docs/                # 统一下载页
```
