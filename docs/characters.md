# 选择两队宠物

打开控制面板，点「左队」或「右队」，或从顶部「桌宠」菜单进入「选择两队宠物与自定义图片」。Mac应用内可按⌘K，Windows也可从托盘菜单进入。

先选要更换的一队，再点角色。两队共享蟑螂、蚂蚁、老鼠，以及奶龙、奥特曼、牛来、乌萨奇、卡皮巴拉、LABUBU、Bongo猫、黄袋鼠，共11个内置选项。可以同款对战，也可以两队分别导入不同图片。点「蟑螂 × 蚂蚁」恢复原始组合，不重开生态、不清空图库。

切换立即生效并保留成长、繁殖、外交和战斗状态；重启后保留左右选择。旧版仅蚂蚁侧的换装设置自动保留为右队，左队保持蟑螂。

八款卡通角色有待机、迈步、吃饭、出招四种姿态，配合呼吸、弹跳、进食鼓胀、拖动、倒下、扫走动画。战斗特效跟随实际出招；观察工具点成员，或点「这一队表演一下」，可以触发回应。蟑螂无论放在哪一队都能飞，其他角色不长虫翅。

「给左队／右队导入图片」支持PNG、JPEG、GIF首帧，20MB以内。透明PNG效果最好；图片自带背景会保留背景。最多保存32个自定义形象，导入图片和原件只留本机，任一队都可选用。单图使用程序动画，不自动生成额外姿态；完全透明或损坏文件会被拒绝，保留已有选择。

两队共用藏卵处、外敌、杀虫剂、扫把及游戏繁殖。没有活成员时，点「放左队卵 · 6」或「放右队卵 · 7」，孵化幼体会显示该队当前角色。场外老鼠和队伍中所选的老鼠是不同对象。

角色图集为本项目制作的衍生视觉，不是官方角色素材。来源参考和生成过程保存在本地生产记录中。
