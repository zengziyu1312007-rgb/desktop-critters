# 角色换装

打开控制面板，点蚂蚁阵营卡片上的「奶龙 · 换装」，或从顶部「桌宠」菜单进入「角色换装与自定义图片」。Windows 也可从托盘菜单进入。

内置奶龙、奥特曼、牛来、乌萨奇、卡皮巴拉、LABUBU、Bongo猫、黄袋鼠。点选立即生效；点「恢复原蚂蚁」切回虫子。切换保留当前成长、繁殖、外交和战斗状态，选择在下次打开时保留。

每款都有待机、迈步、吃饭、出招四种姿态，并配合呼吸、弹跳、进食鼓胀、拖动、倒下、扫走的动作。战斗特效跟随实际出招：奥特曼光线、牛来冲撞、奶龙弹性冲击、LABUBU爪痕等。观察工具点成员，或点图库「表演一下」，可以触发短暂回应。

「导入自己的图片」支持 PNG、JPEG、GIF 首帧，20MB以内。透明 PNG 效果最好；图片带背景时会保留背景。导入保存在本机，最多32个；单张图片使用弹跳、摇摆和星光，不自动生成额外姿态。完全透明或损坏的文件会拒绝导入，保留之前的形象。

如果桌面已经没有活着的蚂蚁，先放几枚蚂蚁卵，等它们孵化后就会显示当前形象。

角色图集为本项目制作的衍生视觉，不是官方角色素材。来源参考和生成过程保存在本地生产记录中。
