Windows 怎么开启？

运行安装包后，从开始菜单打开“桌面有点脏”。面板收起后，双击系统托盘里的图标找回。选工具开始互动，按 Esc 回到鼠标穿透。

Mac 怎么开启？

解压后双击“桌面有点脏.app”。顶部“桌宠”菜单或 Dock 图标可以打开控制面板，原来的虫群存档可以继续使用。

当前安装包尚未进行商业证书签名，系统可能显示发布者提示。Windows 首版的多屏与部分缩放组合仍需实机体验；浏览器识别不准确时，可手动选择版本。
